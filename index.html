RAJ STUDIO

▸

A modern, dark-studio web interface for AI music generation. Turn a description, a set of lyrics, or an existing track into a full song — with real-time progress, polished controls, and zero command-line friction.

Features

Everything you need to make a track

Real-time progress, waveform previews, mic recording, LLM-enhanced captions and lyrics — wrapped around the full ACE-Step V1.5 request contract.

Text → Music

Describe a song in plain English and get a full track. Simple mode drafts everything for you.

Custom studio

Full control over BPM, key, time signature, guidance, seed and batch — every ACE-Step field exposed.

Remix & Repaint

Upload an existing track. Restyle the whole thing or regenerate a single time-range.

Mic recording

Record directly from your microphone. Drag-and-drop upload works too, with a live waveform preview.

LLM-assisted

Enhance caption or lyrics with the 5Hz LM. Create a full sample from a one-line description.

Live progress

Watch queue position, stage and progress percentage tick in real time. Cancel with one click.

Local history

Every take you generate is saved to your browser — playable, downloadable, and re-usable at any time.

Best-in-class UI

Dark studio theme, animated hero, hover-glow cards, and full mobile responsiveness.

Settings

Configure once, forget forever

Point Raj Studio at any ACE-Step backend, dial in your default format, duration, inference steps and guidance, and store an optional API key — all locally in your browser.

  • ✓ Live health probe of your backend URL

Quick start

Up and running in three steps

You need Node 18+ and the ACE-Step backend prerequisites (Python + model weights). The launcher handles the rest.

1

Clone the repository

Grab the full source, including the frontend and the launcher.

git clone https://github.com/Rajeshwar40/Raj-studio.git
cd Raj-studio
2

Launch everything with one command

The launcher boots the FastAPI backend, installs frontend deps on first run, and starts the Vite dev server.

./start.sh
3

Open Raj Studio in your browser

The header status pill turns green when the backend is ready. Then pick a mode and generate.

open http://localhost:5173

Works on every screen

Studio adapts from a wide three-column desktop layout down to a phone. The sidebar collapses into a drawer, the hero rescales, and every control stays touch-friendly.
